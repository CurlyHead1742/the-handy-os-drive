# memtest.iso

**Project:** Memtest86+
**Official source:** https://www.memtest.org/
**Notes:** Open-source memory tester (memtest.org, GPL), not the commercial memtest86.com. Drive has v9.00 x86_64 ISO, unzipped from mt86plus_9.00_x86_64.iso.zip. Lives in _ISO/UTILITIES_MEMTEST/ on the drive. Not checksum-verified.

**Verify before use:** download only from the link above, then check the SHA256 (and PGP signature, if the project publishes one) against the value posted on that official page before writing the image to a drive or booting it.
