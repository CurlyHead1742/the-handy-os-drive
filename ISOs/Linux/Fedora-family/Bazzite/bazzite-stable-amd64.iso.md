# bazzite-stable-amd64.iso

**Project:** Bazzite (stable, amd64)
**Official source:** https://bazzite.gg/
**Notes:** Gaming-focused Fedora Atomic. ISO and -CHECKSUM at download.bazzite.gg. Atomic/immutable system; the live ISO is mainly an installer.

**Verify before use:** download only from the link above, then check the SHA256 (and PGP signature, if the project publishes one) against the value posted on that official page before writing the image to a drive or booting it.
