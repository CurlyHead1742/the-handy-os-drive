# Zorin-OS-15.3-Lite-32-bit.iso

**Project:** Zorin OS (Lite edition, legacy 32-bit build)
**Official source:** https://zorin.com/os/download/ (current releases are 64-bit only; this is the last 32-bit build, mirrored via SourceForge: https://sourceforge.net/projects/zorin-os/files/15/)
**Notes:** Zorin OS is designed to look and feel like Windows, which is why it's on this drive. Zorin dropped 32-bit support after version 15.x, so this is a legacy build (~2019/2020) kept specifically for 32-bit-only hardware (the old Acer). On 64-bit machines, prefer Zorin-OS-18.1-Core-64-bit.iso instead.

**Verify before use:** download only from the link above, then check the SHA256 (and PGP signature, if the project publishes one) against the value posted on that official page before writing the image to a drive or booting it.
