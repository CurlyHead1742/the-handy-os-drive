# antiX-26.1_386-full.iso

**Project:** antiX Linux
**Official source:** https://antixlinux.com/download/
**Notes:** Debian-based, systemd-free, built for old/low-resource hardware. True 32-bit (i386) build — picked specifically for a genuinely 32-bit-only machine (an old Acer), since most mainstream distros dropped 32-bit years ago. "full" edition includes a desktop out of the box.

**Verify before use:** download only from the link above, then check the SHA256 (and PGP signature, if the project publishes one) against the value posted on that official page before writing the image to a drive or booting it.
