# Windows10.iso

**Project:** Windows 10
**Official source:** https://www.microsoft.com/software-download/windows10
**Notes:** Microsoft generates ISO download links dynamically per-session and they expire after 24 hours; visiting from a non-Windows device shows a direct ISO picker instead of pushing the Media Creation Tool. Windows 10 is past mainstream support (ended 2025-10-14) unless enrolled in ESU.

**Verify before use:** download only from the link above, then check the SHA256 (and PGP signature, if the project publishes one) against the value posted on that official page before writing the image to a drive or booting it.
